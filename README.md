# Admin Store Backend

# Sistema de Gestión de Ventas y Almacén

Este proyecto es un backend robusto diseñado para gestionar eficientemente las operaciones de un negocio. Proporciona una API para el manejo integral de ventas de productos, control de inventario, gestión de pedidos y otras funcionalidades esenciales para la administración de un negocio.

## Características principales

- Gestión de inventario
- Procesamiento de ventas
- Control de pedidos
- Administración de productos
- Gestión de clientes
- Reportes y análisis

## Configuración inicial

Sigue estos pasos para configurar el proyecto en tu máquina local:

1. Duplica el archivo `.env.template` y renómbralo a `.env`:
2. Instala los módulos de Node con el siguiente comando: `npm install`
3. Inicia el proyecto: `npm run dev`

## Requisitos previos

- Node.js (versión recomendada)
- npm (normalmente viene con Node.js)
